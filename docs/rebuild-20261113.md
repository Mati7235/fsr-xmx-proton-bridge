## Key finding that avoids a patch of ours

The fork's `0005-anv-cm-sampler-descriptor-table` patch already computes
`table_pc_base = push_size - 4*(nsurf+1)` when the kernel uses a table
sampler: for PRE (11 surfaces + sampler, push 52) it gives **4**, the correct
value, and sets `cm_sampler_pc_off = 48`. A per-profile gate that had been
added during this session was reverted: it duplicated that correction and
broke `0005`. The magenta noise in the previous trace is consistent with the
old driver (no sampler-table), not necessarily with the PRE ABI.
