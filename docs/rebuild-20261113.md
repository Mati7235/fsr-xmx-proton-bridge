## Hallazgo clave que evita un parche nuestro

`table_pc_base = push_size - 4*(nsurf+1)` cuando el kernel usa un sampler de
tabla: para el PRE (11 superficies + sampler, push 52) da **4**, el valor
correcto, y fija `cm_sampler_pc_off = 48`. Un gate por perfil que se había
añadido durante esta sesión se revirtió: duplicaba esa corrección y rompía el
`0005`. El ruido magenta de la traza anterior es consistente con el driver
viejo (sin sampler-table), no necesariamente con la ABI del PRE.
